# CodeAtlas

AI-assisted codebase analysis and interactive architecture visualization, developed as a team project at VibeHack Bucharest in March 2026.

## Project

The platform combines repository analysis, dependency visualization, and a multi-agent LLM workflow with Cartographer, Inspector, Navigator, and Summarizer roles.

**Stack:** Next.js, React, TypeScript, Node.js, Express, Three.js, Tailwind CSS, and Featherless AI/Qwen.

## My contribution

Contributed to frontend/UI, the static repository-analysis pipeline, agent prompts and integration, end-to-end debugging, and the final presentation. This is a team project; the complete application is not solely my work.

## Source

Download and extract [CodeAtlas-source.zip](CodeAtlas-source.zip). The archive preserves the frontend and backend folders. Local environment files, dependencies, caches and development-assistant files are excluded.

Original team repository: https://gitlab.com/Eroooooooool/hackathon-vibehack

For a local setup, install dependencies separately in `frontend/` and `backend/`; run `npm run dev` in each. Supply your own required API/authentication settings locally. This portfolio archive has not been redeployed or independently build-tested.
